Diagonal Count

Puzzle by Alexander Bogomolny (cut-the-knot.org)

Game: join up corners of the polygon with straight lines that never cross each other, and keep going until no more will fit.
How to play: drag from one corner to another, or tap one corner and then the other. Corners next door to each other don't count — that line is just a side. Guess how many lines you will fit before you start.
Diagonals: 0 / 2
Look for the math

Bogomolny's page sets this as an experiment rather than a lesson: draw non-crossing diagonals however you like, and work out the rule for yourself before reading on. Try a few different polygons above and watch the second number in the counter. Whatever order you draw them in, and whichever diagonals you pick, you fill a convex polygon with n corners using exactly n − 3 of them — never more, and you can never get stuck on fewer.

Counting the angles

When no more diagonals fit, the polygon has been cut into triangles. Say there are T of them and you drew D diagonals. Those triangles have 3T sides between them, and each of those sides is either an edge of the polygon, counted once, or a diagonal, counted from both sides:

3T = n + 2D

Now add up all the angles. The triangles contribute 180° × T, and because no diagonal crosses another, every one of those angles sits inside a corner of the polygon — so they must add up to the polygon's own angle total, 180° × (n − 2). Putting the two together, 180(n − 2) = 180(n + 2D)/3, which tidies up to D = n − 3. Feed that back into the first equation and you get the number of pieces for free: T = n − 2.

Or cut along one diagonal

Here is the same result by induction. A triangle has no diagonals, so D = 0 = 3 − 3 starts us off. For a bigger polygon, finish the drawing and then cut along any one of your diagonals. You get two smaller polygons, each already full — any diagonal you could add to one would have been legal in the original too. If they have n₁ and n₂ corners then n₁ + n₂ = n + 2, because the cut line becomes a side of both. Their diagonals are D − 1 between them, since the cut itself is no longer one, so (n₁ − 3) + (n₂ − 3) = D − 1 — and that rearranges to D = n − 3 again.

How many are there altogether?

That is a different question, and an easier one. From each of the n corners you can reach n − 3 others, which counts every diagonal twice, once from each end: n(n − 3)/2 in all. A pentagon has 5 and a 40-gon has 740. The puzzle is that no matter which of them you start with, you always run out of room after the same small handful.

One last question the page raises: the number of diagonals is always the same, but the pictures are not. Counting how many different ways a polygon can be cut up like this gives the Catalan numbers — 1, 2, 5, 14, 42, 132 for polygons with 3, 4, 5, 6, 7, 8 corners. Try to find all 5 for the pentagon.
