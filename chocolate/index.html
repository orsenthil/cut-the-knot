Breaking Chocolate Bars

Puzzle by Alexander Bogomolny (cut-the-knot.org)

Goal: break the bar into single squares in as few snaps as possible.
How to play: click any line inside a piece to snap it there.
Look for the math

This is a browser version of Alexander Bogomolny's "Breaking Chocolate Bars". However you snap it — big pieces first, one row at a time, at random — a bar with R rows and C columns always takes exactly RC − 1 breaks to reduce to single squares. There's no way to do it in fewer, and no way to need more.

Counting pieces instead of squares

Every break, wherever you make it, turns exactly one piece into two — that's all a break can do. So each break raises the piece count by exactly 1. A whole bar starts as 1 piece, and you're done when there are RC pieces (one per square), so the number of breaks is forced:

breaks = (final pieces) − (starting pieces) = RC − 1

This kind of argument — find a quantity that changes by a fixed amount on every move — is the same idea behind the invariants in the other games on this site; here the "invariant" is simplest possible: the count just goes up by exactly one, forever, so the total is fixed before you make a single move.

Or prove it piece by piece

The same fact also falls out of induction on the number of squares N. A single square needs 0 breaks — that's the base case. Split any bar of N squares into two smaller bars of m1 and m2 squares (m1 + m2 = N). If each smaller bar needs one fewer break than its square count, finishing both plus the break that made the split costs:

1 + (m1 − 1) + (m2 − 1) = (m1 + m2) − 1 = N − 1

which is the same formula one size up — so it holds for every N once it holds for 1.

The same fact shows up everywhere

Bogomolny lists several puzzles that are secretly the same problem: cutting 25 tree trunks into 75 logs takes 50 cuts; a 75-team single-elimination tournament needs exactly 74 matches to crown a winner; an N-piece jigsaw puzzle takes N−1 moves to assemble. Each one is "start with many independent pieces, combine one pair at a time, count how many combinations reach a single whole" — and the answer is always (pieces) minus 1.

Try it: break a 4×5 bar as fast or as slowly as you like — big even splits, one row at a time, or totally at random — it's always 19 breaks.
