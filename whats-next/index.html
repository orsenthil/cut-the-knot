What's Next?

Puzzle by Alexander Bogomolny (cut-the-knot.org)

Game: you see six numbers that follow a secret rule. Work out the rule and say which number comes next.
How to play: type your answer and press Check. If you get it wrong you get a hint, and you can try the same numbers again.
    Look for the math

    Each sequence comes from one of nine rules, with small random numbers plugged in. Most of them are recurrences: each term is made from the ones before it.

    The nine rules

    Add the same number each time (a, a+d, a+2d, …). Multiply by the same number (a, aq, aq², …). Add the last two terms, as in the Fibonacci numbers, or the last three. Take turns adding and multiplying, or take turns adding two different numbers. Use a formula an² + bn + c. And the odd one out: look-and-say, where each term reads the previous one aloud. 21 is "one 2, one 1", so the next term is 1211, then 111221, then 312211.

    The ninth rule is "shifted powers", c + bqn. In Bogomolny's applet the shift c is always 0, so it is really another geometric sequence, and this port does the same. Its "add the same number" sequences also always start at 0 or below and never go up.

    Differences find the polynomial

    Subtract each term from the next. For an² + bn + c those differences are a(2n+1) + b, a sequence that goes up by the same step each time, and subtracting again gives the constant 2a:

    1, 4, 9, 16, 25, 36 → 3, 5, 7, 9, 11 → 2, 2, 2, 2

    So when the second differences settle down, run them backwards: the next difference is 13 and the next term is 49.

    Is there only one right answer?

    Inside this game, yes. Every rule and every set of numbers the applet can draw gives 2,673 different sequences in all. Checking every one of them, whenever two rules make the same six terms (like 3, 6, 12, 24, 48, 96), they also agree on the seventh.

    Outside the game, never. Six numbers fit infinitely many rules: through any seven points there is a polynomial that makes the next term anything you like. Bogomolny's own example: what follows 7, 14, 21, 28? If those are the dates of the Mondays in March, the next one is April 4, not 35.

    Stuck? Write the differences under the numbers, then the ratios. One of the two usually gives the rule away.
