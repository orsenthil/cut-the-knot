Look for the math

A two-person zero-sum game gives one player exactly what the other loses. The four numbers in this table are enough to show the two possible kinds of stable play.

A square that settles everything

The row player wants a bigger number, so they look for the smallest number in each row. The column player wants a smaller number, so they look for the biggest number in each column. A number that is both is a saddle point. Neither player needs to guess: both can choose its row or column every time.

When no single choice is safe

Otherwise, each player can protect themselves by mixing their two choices. If the entries are a b / c d, the row player chooses its first row with probability (d − c)/(a − b − c + d); the column player chooses its first column with probability (d − b)/(a − b − c + d). The plot shows why: at the crossing, neither choice can improve the other player's result.

Minimax

The minimax theorem says these two ways of protecting yourself meet at the same value. In a 2 by 2 game that value is (ad − bc)/(a − b − c + d). The applet displays a mixture only when both probabilities are strictly between 0 and 1.

Make a matching-pennies table: 1 and −1 on one diagonal, −1 and 1 on the other. Both players must choose each option half the time.
