Dawson's Kayles

Puzzle by Alexander Bogomolny (cut-the-knot.org)

Game: skittles stand in a ring and every move knocks down two that are side by side. Knock down the last pair and you win.
How to play: click the small dot between two standing skittles to knock both over. A skittle with nobody standing beside it can never be knocked down.
Look for the math

This is a browser version of Alexander Bogomolny's applet "Dawson's Kayles", a 1930s game described in Berlekamp, Conway and Guy's Winning Ways for Your Mathematical Plays. Each move takes two neighbouring skittles, and the player who cannot move has lost.

The ring falls apart into separate games

Knock out a pair and the skittles on either side of the hole stop being neighbours. So after a move or two the board is a handful of separate arcs, and no move can ever involve two of them at once. A lone skittle is dead weight: nothing beside it, so nothing can ever remove it. That is the structure a Sprague–Grundy argument needs. Give every arc length a number G(n), its nimber, and the whole board behaves like one heap of size

G(arc₁) XOR G(arc₂) XOR …

You are lost exactly when that total is 0, so winning means handing it back at 0 every turn.

Working the numbers out

Taking the pair that sits a places into a row of n leaves rows of a and n − 2 − a, so the values come from the mex rule — the smallest whole number that is not among the options:

G(n) = mex { G(a) XOR G(n − 2 − a) : 0 ≤ a ≤ n − 2 }

Starting from G(0) = G(1) = 0 that gives 0, 0, 1, 1, 2, 0, 3, 1, 1, 0, 3, 3, 2, 2, 4, 0, 5, 2, 2, 3, … The arcs worth handing over are the ones with G = 0: lengths 0, 1, 5, 9, 15, 21, 25, 29, 35, 39, 43, 55, 59. The applet stores 137 of these values in its code; this port recomputes them with the mex rule, and the port's test checks that all 137 come out the same.

A pattern that almost repeats

There is no formula for G(n), but the list is eventually periodic: G(n + 34) = G(n) for every n except six stubborn ones, namely 0, 15, 17, 32, 35 and 52. Past that the whole sequence just repeats in blocks of 34. In the notation of Winning Ways this is the octal game ·07, and, as Bogomolny notes, its values are the values of Dawson's chess with an extra 0 pushed on the front.

A full ring is not a row

An untouched ring has no ends, so every opening move does the same thing: whichever pair you take, what is left is one arc of n − 2. There is no choice to get wrong and no choice to get right. The ring of n is therefore won by whoever moves first exactly when G(n − 2) = 0 — rings of 7, 11, 17, 23, 27, 31 and 37 in the range on offer here, and nothing else.

Tick "Full circle" with 18 skittles and press "Make Move": the game is lost for whoever goes first, so let the computer have it. Then try 17 and open yourself.
