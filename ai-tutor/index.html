AI Tutor

coolmaths has a tutor that AI assistants can connect to. Once connected, you can ask your assistant about any game here and it will answer from the site’s own explanations and code, not from memory.

The address of the tutor

https://coolmaths-tutor.fly.dev/mcp

It is a remote MCP server. It is free, read-only, and needs no sign-in.

Connect your assistant

Claude Code (in a terminal):

claude mcp add --transport http coolmaths https://coolmaths-tutor.fly.dev/mcp

Claude on claude.ai or Claude Desktop:

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Name it coolmaths and paste the address above.
  4. Save, then switch the connector on in a new chat.

Any other MCP client (an editor, another assistant, your own program): add a server of type streamable HTTP with the same address. For example, in a client that reads a JSON settings file:

{
  "mcpServers": {
    "coolmaths": {
      "type": "http",
      "url": "https://coolmaths-tutor.fly.dev/mcp"
    }
  }
}

Talk about a game

Once it is connected, ask in plain words. For example:

  • “Tutor me on the hourglass puzzle, but don’t tell me the answer yet.”
  • “Which games here are about parity?”
  • “Explain the idea of an invariant using the games on coolmaths.”
  • “Quiz me on recursion.”
  • “Use the real game logic to solve the 7 and 11 minute hourglass for 15 minutes.”

What the assistant can do

  • Search and browse every game by name, idea or difficulty.
  • Read the rules and the maths of a game, the same text you see under Look for the math.
  • Explain a concept by pulling together every game that uses it.
  • Run the game’s real code for games that have it, to show a strategy at work.
  • Teach step by step. Built-in prompts (tutor, quiz_me, explain_like_im) have it let you play and guess first, give hints, and only then name the idea.

Let it see your own progress (optional)

For a tutor that knows what you have played and which game is open on your screen, add a second connector with this address:

https://coolmaths-tutor.fly.dev/mcp/me

Your assistant will send you to coolmaths to sign in with Google or GitHub and press Allow. After that it can suggest what to play next and help with the position you are looking at. It can only read, only your own record, and you can switch it off any time on your profile. Details are on the privacy page.

Want a person instead?

A teacher can work with you one to one for 30 minutes. See the Human Tutor page.

The server’s code and a full list of its tools are in the mcp folder on GitHub.
